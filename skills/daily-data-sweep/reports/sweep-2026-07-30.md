## Method note

Every count in this report is an exact server-side `totalCount` obtained with `limit: 1`, not a
truncated scan. Field paths were validated against `well_get_schema(transactions)` before querying —
which is load-bearing, not hygiene: an **invalid field name returns `success: true, totalCount: 0`**
in the multi-workspace fan-out path, indistinguishable from a clean workspace. An unvalidated empty
result is INCONCLUSIVE, never a pass.

`records_url` values are passed through verbatim from the query responses; none were constructed.
